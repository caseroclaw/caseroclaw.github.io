# caseroclaw.github.io

Página índice de las herramientas abiertas que publica [Plataforma IA](https://plataformaia.com), consultora de automatización con IA para pymes en España (Madrid, trabajo remoto en todo el país).

**Sitio publicado:** https://caseroclaw.github.io/

## Qué hay aquí

| Herramienta | Repositorio | Demo |
|---|---|---|
| `verifactu-qr` — QR tributario de VeriFactu con validación de NIF/NIE/CIF (CLI + servidor MCP) | [caseroclaw/verifactu-qr](https://github.com/caseroclaw/verifactu-qr) | [web](https://caseroclaw.github.io/verifactu-qr-web/) |
| `radar-ai-act` — clasificador de obligaciones del Reglamento (UE) 2024/1689 por caso de uso | [caseroclaw/radar-ai-act](https://github.com/caseroclaw/radar-ai-act) | [radar](https://caseroclaw.github.io/radar-ai-act/) |
| `roi-automatizacion-ia` — calculadora de amortización de una automatización | [caseroclaw/roi-automatizacion-ia](https://github.com/caseroclaw/roi-automatizacion-ia) | [calculadora](https://caseroclaw.github.io/roi-automatizacion-ia/) |

Las tres son gratuitas, se ejecutan en el equipo o el navegador del usuario y no envían datos a ningún servidor propio.

## Estructura

- `index.html` — página única, sin JavaScript de terceros ni fuentes externas; incluye JSON-LD (`ItemList` + `Organization`).
- `robots.txt`, `sitemap.xml` — un solo URL canónico.
- `README.md`, `LICENSE` — MIT.
